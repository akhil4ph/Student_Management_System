# Student_Management_System

A standalone desktop application built using **Java** and **JDBC** to manage student records efficiently. This project demonstrates how to connect a Java application to a **MySQL** database and perform full CRUD operations.

##  Features
- **Create:** Add new student records to the database.
- **Read:** Fetch and display all student details.
- **Update:** Modify existing student information.
- **Delete:** Remove a student record from the database.

##  Tech Stack
- **Language:** Java (Core)
- **Database:** MySQL
- **API:** JDBC (Java Database Connectivity)
